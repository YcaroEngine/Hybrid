# Hybrid Engine (1.21.11 Multi-Versão)

Motor de servidor híbrido Multi-Versão para Minecraft (**base 1.21.11**) que unifica **Java e Bedrock em um só** (mesma porta padrão ou portas extras opcionais), com suporte nativo a todos os **Mods (NeoForge/Forge/Fabric)**, **Plugins (Paper/Purpur/Spigot)** e todas as versões em geral.

## Como Instalar (Obrigatório Base NeoForge)

1. No painel da sua hospedagem (ou PC), selecione o software **NeoForge 1.21.11**.
2. Abra o gerenciador de arquivos e **apague o `server.jar` original** do NeoForge.
3. Envie **apenas o `server.jar` do Hybrid** para a pasta principal do servidor.
4. Inicie o servidor utilizando **Java 21**.
5. Na primeira inicialização, o **Hybrid** baixa e monta automaticamente toda a estrutura do NeoForge 1.21.11, cria as abas/pastas `/mods` e `/plugins`, gera o `server.properties` completo e ativa a entrada **Java + Bedrock** na mesma porta!
