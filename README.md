# Hybrid Engine (BETA)

**The ultimate Minecraft server software: Hybrid, Multi-version, and featuring Native Cross-Play.**

Hybrid is a revolutionary, beta-stage server software designed to unify the entire Minecraft ecosystem into a single file. No more setting up dozens of external bridges or choosing between mods and plugins—simply replace your current `server.jar` with Hybrid and you’re all set!

## Key Features

* **Universal Multi-Version:** Choose any Minecraft version you’d like to play, with no complications.
* **Fully Hybrid (Mods + Plugins):** Built-in support for running plugins (Paper, Purpur, Spigot) alongside mods (NeoForge and Fabric) on the same server.
* **Native Bedrock Support:** Players on mobile, console, and Windows (Bedrock Edition) can join your Java server natively—no need to install Geyser or Floodgate separately.
* **Plug & Play Installation:** Delete your old `server.jar`, replace it with the Hybrid `server.jar`, and start your server.

# Hybrid Engine (BETA)

**O software definitivo para servidores de Minecraft: Híbrido, Multi-versão e com Cross-Play Nativo.**

Hybrid é um software de servidor revolucionário em fase beta, projetado para unificar todo o ecossistema do Minecraft em um único arquivo. Chega de configurar dezenas de pontes externas ou ter que escolher entre mods e plugins — basta substituir seu `server.jar` atual pelo Hybrid e pronto!

## Principais Recursos

* **Multi-Versão Universal:** Escolha qualquer versão do Minecraft que você quiser jogar, sem complicações.
* **Totalmente Híbrido (Mods + Plugins):** Suporte integrado para rodar plugins (Paper, Purpur, Spigot) junto com mods (NeoForge e Fabric) no mesmo servidor.
* **Suporte Nativo ao Bedrock:** Jogadores de celular, console e Windows (Bedrock Edition) podem entrar no seu servidor Java nativamente — sem precisar instalar Geyser ou Floodgate separadamente.
* **Instalação Plug & Play:** Apague seu `server.jar` antigo, substitua pelo `server.jar` do Hybrid e inicie o servidor.
