# Hybrid Engine (BETA)

**The ultimate Minecraft 1.21.11 server software: Hybrid (NeoForge + Paper), Multi-version, and featuring Native Cross-Play.**

Hybrid is a revolutionary, beta-stage server software designed to unify the entire Minecraft ecosystem into a single file. Run **NeoForge 1.21.11 mods** alongside **Paper plugins**, and allow players from **Java Edition** and **Bedrock Edition (26.60, 26.3, 26.2, and more)** to play together on the exact same port—no manual bridge configuration required.

## Key Features

* **Fully Hybrid 1.21.11 (NeoForge + Paper):** Native support for running **Paper/Spigot plugins** (`plugins/`) alongside **NeoForge 1.21.11 mods** (`mods/`) on the same world.
* **Native Cross-Play (Same Port & NetherNet):** Players on mobile, console, and Windows (Bedrock Edition) can join your Java server using the same IP and port, with automatic account handling (no dot `.` prefix) and NetherNet support.
* **Multi-Version Client Support:** Allows connections from **Bedrock 26.60, 26.3, 26.2**, and other versions, as well as multiple **Java Edition** versions.
* **Simplified Bedrock Packs (`bedrock-packs/`):** Drop your `.mcpack`, `.mcaddon`, `.zip`, or uncompressed pack folders directly into `bedrock-packs/` for automatic synchronization.

## How to Install (Hosting or PC)

1. Go to the **[Releases](../../releases)** tab and download the latest **`server.jar`**.
2. On your hosting panel (or local PC folder), select **NeoForge 1.21.11** as your server software.
3. Delete the default `server.jar` generated in your server directory.
4. Upload the Hybrid **`server.jar`** in its place.
5. Start your server and wait for the automatic setup to complete.
