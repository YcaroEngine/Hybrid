# Hybrid Engine (1.21.11 Multi-Version)

Hybrid Multi-Version server engine for Minecraft (**1.21.11 base**) that unifies **Java and Bedrock into one** (same default port or optional extra ports), with native support for all **Mods (NeoForge/Forge/Fabric)**, **Plugins (Paper/Purpur/Spigot)**, and all versions in general.

## How to Install (NeoForge Base Required)

1. In your hosting control panel (or PC), select the **NeoForge 1.21.11** software.
2. Open the file manager and **delete the original `server.jar`** from NeoForge.
3. Upload **only the Hybrid `server.jar`** to the main server directory.
4. Start the server using **Java 21**.
5. On first startup, **Hybrid** automatically downloads and builds the entire NeoForge 1.21.11 structure, creates the `/mods` and `/plugins` folders, generates the full `server.properties`, and enables **Java + Bedrock** crossplay on the same port!
